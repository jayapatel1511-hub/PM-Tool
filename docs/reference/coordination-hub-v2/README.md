# Coordination Hub V2 visual reference

`Coordination Hub v2.dc.html`, `hub-theme.css`, and `support.js` are the three files needed from `~/Downloads/Design scope clarification.zip` to inspect the V2 prototype. They are preserved unchanged. The V1 file and the separate Phone and Email prototype are not product references.

**Use V2 only for visual cues.** Its layout, palette, typography, spacing, sample data, navigation, labels, interactions, and release badges are illustrative. This prototype is not a design specification, a source of feature scope, or implementation code. In particular, its Phase 2 badges and read-only Timeline reflect an earlier prototype; the user-confirmed first-release requirements in the product specification and packets govern those features.

The six-panel image at `../six-view-workspace.png` records the earlier feature-scope discussion. The user confirmed the six views for the first release and task-hour entry under Time. Neither image nor prototype fixes the final visual design. Design decisions should be validated against the product workflows, accessibility requirements, and the functional acceptance criteria.

The HTML is an exported prototype with a support script and a stylesheet that imports web fonts. Treat it as reference material, not application source.
