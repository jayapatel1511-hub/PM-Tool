**Rounds and lifecycle.** New incoming receipts require the actual current started round. An explicit NewRound selects real known-author issues. Preserve all earlier rounds/approvals, original ExternalReview/party/received date/code and actual designation events. Carry unresolved canonical findings with `CarriedFromId`; map current source by the same real deliverable, preserve the original incoming issue separately, reset Response/EvidenceUrl/ResponseOutcome and status to Open, and revalidate carried verifier independence against both old and new known author sets. Invalid inherited designation blocks until ordinary PM replacement; it never silently grants another person authority. Carry ancestry must be same-project/package, acyclic and within the established chain-depth rule; unknown/missing ancestry blocks.

Explicit source/discipline removal requires existing PM reason/RemovalImpact. **Receipts.** Preserve existing operation names/receipt storage and exact internal serialization/hash parity.
