**Preserve Admin + ReadOnly exactly.** `Actor.ReadOnly` at `Permissions.cs:12` is `Has(ReadOnly) && !Admin`; Admin is explicitly never effectively Read Only. The source test at `tests/Hub.Tests/Domain/PermissionSweepTests.cs:288` also documents that behavior. Root confirmed preservation of this canonical predicate.
