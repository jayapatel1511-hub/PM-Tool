# Approved Paper hero assets

Jay approved the Paper hero on 2026-10-03. The landing component preserves its Terrace wordmark, centred serif heading, amber/sage glow, original raw engineering sketches and straight Task Board preview.

The Board uses a script-free SVG image of a rendered DOM snapshot of the maintained Tuesday interface and an unchanged build stylesheet plus fixed image viewport dimensions. All records were fictional and served by an isolated local GET fixture. The native JPEG remains a image-error fallback. This static public example contains no live project data, application scripts or active destinations. The image is decorative and hidden from accessibility. It works with the existing CSP and framing protections. Fonts are served locally with their SIL Open Font License notices in fonts/. Routes, sizes and hashes are recorded in capture.json. The actual login and authenticated app remain controlled by the existing AuthGate.

Original Lucide artwork notice is retained in THIRD-PARTY-NOTICES.txt. Self-hosted Google Fonts supply DM Sans, Instrument Serif and decorative Caveat with system fallbacks. No additional packages are introduced.
